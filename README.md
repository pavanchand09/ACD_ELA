# Automata & Formal Languages

This project demonstrates **Finite Automata concepts using Python and Graphviz**.

### Contents

* DFA construction and visualization
* NFA construction and visualization
* NFA to DFA conversion using subset construction
* Transition tables and final states

### Technologies

* Python
* Graphviz
* Jupyter Notebook / Google Colab

### Run

Open `ACD_ELA_D6.ipynb` in **Jupyter Notebook or Google Colab** and run the cells sequentially.
